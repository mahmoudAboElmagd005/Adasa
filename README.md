## 📋 Project Description

**عدسة (Adasah)** is a photography blog web application built with React.

The project provides an interactive interface for browsing photography articles, searching and filtering posts by category, reading full article pages with a dynamic table of contents, and discovering related content and authors.

The application is fully data-driven, rendering all pages from a single JSON dataset and updating the interface dynamically using React Router.

---

## ✨ Features

* 🏠 **Home Page** - Featured articles, latest posts, and category highlights
* 🔎 **Article Search** - Search articles by title and excerpt
* 🏷️ **Category Filtering** - Filter articles by photography category, synced with the URL
* 🗂️ **Grid / List View** - Switch between grid and list layouts in the blog page
* 📰 **Article Page** - Full article view with auto-generated headings and table of contents
* 🧑‍🤝‍🧑 **Related Articles** - Suggested articles from the same category
* 👥 **Authors Page** - Unique authors extracted automatically from articles
* 📱 **Responsive Interface** - Designed to work across different screen sizes
* 🌗 **RTL Support** - Fully right-to-left Arabic layout
* 🚫 **404 Page** - Custom not-found page for unknown routes
